# Эмулятор командной строки (вариант 14)

Учебный проект по дисциплине «Конфигурационное управление». Язык: Python 3.9+, графический интерфейс: Tkinter.

## 1. Общее описание

Программа имитирует работу в командной строке UNIX-подобной ОС и работает в графическом окне.

- Заголовок окна берётся из реальной ОС: `Эмулятор - [имя_пользователя@имя_компьютера]`.
- Поддерживаются кавычки, комментарии `#` и переменные окружения (`$HOME`, `${USER}`).
- Об ошибках (неизвестная команда, неверные аргументы) программа сообщает красным текстом в окне.
- Все вызовы команд записываются в XML-журнал.
- Команды можно выполнить из стартового скрипта: в окне видны и ввод, и вывод.

Структура репозитория:

- `src/emulator.py` — весь код эмулятора;
- `tests/` — автотесты (`test_emulator.py`) и скрипты эмулятора (`tests/scripts/*.emu`);
- `run.bat`, `test.bat` — запуск программы и тестов.

## 2. Описание всех функций и настроек

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs ПУТЬ` | директория на диске, из которой загружается VFS (без параметра — VFS по умолчанию в памяти) |
| `--log ПУТЬ` | путь к XML лог-файлу |
| `--script ПУТЬ` | стартовый скрипт с командами |
| `--headless` | работа в терминале без окна (для проверок) |

При запуске все параметры выводятся строками `[debug] ...`. Ошибки запуска печатаются в консоль, код возврата 1.

### Формат лога

Каждый вызов команды — элемент `<event>` с полями `<time>` (дата и время), `<command>`, `<args>` и `<error>`
(пусто, если ошибки не было).

### Стартовый скрипт

Одна команда на строку. Пустые строки пропускаются, строки с `#` — комментарии.

### Команды

| Команда | Описание |
|---------|----------|
| `ls`, `cd` | заглушки: печатают своё имя и аргументы |
| `exit` | завершить работу |

### Основные функции в `src/emulator.py`

- `parse_line`, `expand_vars` — разбор строки и переменные окружения;
- `XmlLog` — запись XML-журнала; `read_script` — чтение стартового скрипта;
- `Emulator` — выполнение команд (`execute`, методы `cmd_*`);
- `App` — окно Tkinter;
- `main` — точка входа.

## 3. Сборка и запуск тестов

Сборка не нужна. Нужен Python 3.9+ (Tkinter входит в установщик для Windows).

```
run.bat                 запуск эмулятора
test.bat                запуск тестов
stage2.bat              проверка параметров командной строки
```

Чтобы сценарии выполнялись без окон, перед запуском выполните `set EMU_FLAGS=--headless`
(в PowerShell: `$env:EMU_FLAGS="--headless"`).

## 4. Примеры использования

```
run.bat
run.bat --script tests\scripts\stage2.emu
run.bat --log logs\run.xml --script tests\scripts\stage2.emu
```

Пример диалога:

```
user@host:/$ ls
ls: аргументы = []
user@host:/$ foo
foo: команда не найдена
user@host:/home/user$ exit
```
